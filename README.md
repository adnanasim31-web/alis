# Portfolio

A simple, responsive personal portfolio landing page built with plain HTML, CSS, and JavaScript — no build step.

## Features

- Sections: hero, about, projects, experience, contact
- Light/dark mode (follows system preference, with a manual toggle)
- Mobile navigation menu
- Scroll-reveal animations (respects reduced-motion settings)

## Run locally

Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Customize

- Replace "Your Name", bio text, project cards, and experience entries in `index.html`.
- Update social links and the `mailto:` address in the contact section.
- Change the accent color via `--accent` in `styles.css`.
